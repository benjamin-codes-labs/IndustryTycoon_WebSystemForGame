## 背景

現在正處於競爭激烈的社會，作為一間跨國公司的老闆，想在數不勝數的企業中脫穎而出，除了壯大自身，還需限制對手的發展，淘汰對手。最簡單、最直接的方法，便是控制資源並善用資源。

你的任務是利用手中的棋子有策略地行動，佔據並控制當地的自然資源，壯大自身，並在經濟層面上逐步削弱對手公司的實力，使其倒閉、破產，最終成為最後的、或最富有的產業大亨！

## 遊戲組成

| 組件 | 用途 |
|---|---|
| 地圖塊（20 張） | 組成棋盤。不同顏色的區域代表不同資源點：木材、鐵、黃金、原油、魚、農作物、肉、石頭、煤炭、畜牧。 |
| 角色牌 | 每位角色都有獨特的能力、每回合支出與生命值（見[角色](#角色)）。 |
| 特殊技能牌 | 一次性的特殊效果，可直接影響戰局（見[特殊技能牌](#特殊技能牌)）。 |
| 建築塊 | 放置在棋盤上的收集廠與加工廠。 |
| 骰子（4 顆） | 決定行動順序及部分能力的結果。 |
| 棋子 | 四種顏色的國王、皇后、將軍、城堡、主教、騎士及士兵。 |
| 配套系統 | 記錄金錢、資源、建築、棋子及通貨膨脹。 |

**遊戲人數**：2–4 人 · **遊戲時間**：約 20–40 分鐘

## 遊戲準備

1. 擲骰決定**地主**。地主第一個行動，使用白色棋子；其他玩家按行動順序使用黑、藍、紅色棋子。各玩家擲兩顆骰子決定行動順序，點數和最小者先行動。
2. 地主隨機抽取兩張地圖；裁判把所有牌分別洗勻，放在一旁作為牌庫。
3. 每位玩家隨機抽取兩張角色牌，自選其一。
4. 地主把地圖放在任意位置，地圖之間至少相隔三格。
5. 按行動順序，各玩家把基地放在任意空白區域。基地周圍的八格為**基地區**。
6. 每位玩家初始獲得一個**國王**、一個**皇后**及一個**士兵**，放在自己的基地區。
7. 在系統中以相同的名稱、角色及行動順序開始新遊戲。

## 回合流程

### 1. 準備階段

- 拿取資源或金錢。收集廠的產出由系統自動發放。
- 若上回合使用了特殊技能，抽一張特殊技能牌。

### 2. 移動階段

- 每個棋子每回合只能移動**一次**。
- 移動到敵方棋子所在的格子即可攻擊並消滅該棋子。棋子死亡後不能再上場。
- 棋子到達資源區域時，可在該處建造收集廠（先在系統中付款，再放置建築塊）。
- 每位玩家每回合只能建造**一座建築**。加工廠只能建在自己的基地區內。
- 本回合購買的棋子放在備區或基地區。

### 3. 出牌階段

- **保險**：在系統中付款後，抽一張保險牌公開放在面前。該保險在本回合結束前保護指定玩家的建築及棋子免受任何傷害（被保護方的棋子攻擊其他玩家的國王時除外）。每回合限購一份，並須在下回合開始時棄置。
- **特殊技能**：每張牌只可使用一次，使用後棄置。每回合使用數量不限，除例外情況外只能在己方回合使用。手牌上限為**己方國王生命值 + 1**。

### 4. 回合結束

在系統中按下 **下一位玩家**，輪到下一位玩家行動；所有玩家都行動過一次後，該輪結束。

## 戰鬥與國王

- 攻擊敵方國王會令其扣除 **1 點生命值**。國王生命值歸零即死亡，其擁有者被淘汰。
- 無論結果如何，攻擊國王的棋子都會返回己方基地區。
- 在系統中記錄被擊殺的棋子（**擊殺棋子**）；擁有擊殺獎勵的角色會自動獲得獎勵。

## 勝負條件

當出現以下任一情況時，遊戲結束：

1. **最後倖存者**：國王被消滅的玩家即被淘汰。只剩一位玩家時，該玩家勝出。
2. **破產**：連續**三個回合**以零金錢開始的玩家會被淘汰（由系統自動處理）。
3. **牌庫耗盡**：特殊技能牌被抽完後進入**加時**。剩餘玩家各擲一顆骰子，點數最大者可移動或旋轉一塊地圖；把所有特殊技能牌洗勻放回牌庫。牌庫再次耗盡時，完成該輪後金錢最多者勝出；如平手，依次比較建築數量及棋子數量，仍然平手則為和局。

若玩家同意提前結束，可參考系統的排行榜，按總資產決定勝負。

## 經濟規則

| 規則 | 數值 |
|---|---|
| 起始金錢 | 1,500 |
| 每回合支出（回合結束時扣除） | 角色基本支出 + 每購買一隻棋子 10 |
| 最低餘額 | 支出不會令金錢低於 0 |
| 保險 | 500（不受通貨膨脹影響） |
| 建築上限 | 每位玩家 15 座，全場 28 座 |
| 加工產品 | 在投入資源的玩家回合結束時入帳 |

**收集廠**在擁有者每個回合開始時產出原料。**加工廠**把原料轉化為加工品，產出數量為：

```text
產出數量 = round( Σ（原料價格 × 數量）× 加值倍率 ÷ 加工品價格 )
```

計算時使用當時的市場價格。排行榜上的**總資產**為金錢加上所持資源及棋子的市值；合成棋子的價值等於其組成棋子的價值總和。

## 通貨膨脹

每輪開始時，系統會重新計算所有價格（資源、收集廠、加工廠及棋子），倍率顯示於頁首的 **通貨膨脹率**。模型會量度每位玩家的平均財富，並按其變化幅度調整價格。

$$\zeta_n = M + I_{n-1}\sum_{r} w_r k_r + 50B + 100S \qquad P_n = \frac{\zeta_n}{N}$$

$$I_n = 1 + 0.2\, d_n \, \frac{P_n - P_{n-1}}{P_n}$$

| 符號 | 意思 |
|---|---|
| $M$ | 所有玩家的現金總額 |
| $k_r$、$w_r$ | 所有玩家持有原料 $r$ 的總數，及其通膨權重 |
| $B$、$S$ | 場上建築總數，及所有玩家擁有的棋子總數 |
| $N$ | 玩家人數 |
| $I_{n-1}$ | 上一輪的倍率（首次調整前為 1） |
| $d_n$ | 每輪隨機取 $+1$ 或 $-1$ |
| $P_{n-1}$ | 上一輪的物價水準；首次調整時取 $0.95\,P_n$ |

所有價格乘以 $I_n$ 後四捨五入至整數。由於首輪的初始值設定，第一次調整必定為 ±1%。

### 特殊技能牌

| 技能 | 效果 |
|---|---|
| 無懈可擊 | 抵消另一張牌的效果。 |
| 革命 | 獲得一隻除國王、皇后及將軍以外的棋子。 |
| 玉石俱焚 | 若己方棋子的價值不低於敵方棋子，雙方棋子同歸於盡。 |
| 回血 | 為指定玩家的國王回復 1 點生命值，國王生命值為 0 時亦可使用；可在任何時候使用，包括其他玩家的回合。 |
